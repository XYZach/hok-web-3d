# 王者峡谷 · Web 3D(粉丝自制 5V5 MOBA)

> ## 🎮 立即游玩:https://xyzach.github.io/hok-web-3d/
>
> 电脑 / 手机浏览器直接打开,无需安装任何东西。建议收藏或直接把链接分享给朋友。

一个用 Three.js 从零构建的浏览器 3D MOBA,致敬《王者荣耀》的玩法与 HUD 观感。
**非官方粉丝作品,与腾讯无关;所有模型、贴图、音效均由程序实时生成,无任何官方素材。**

## 玩法

- 5V5 人机对局:三路兵线、18 座防御塔(推塔链:一塔→二塔→高地塔→水晶)
- 三个可选职业:圣殿骑士(战士)、月华法师(法师)、鹰眼射手(射手),各 3 个技能 + 大招
- 召唤师技能:闪现 / 治疗 / 回城;技能加点、装备商店(8 件装备)、补刀经济
- 野区:红蓝 BUFF、4 组小野怪、暴君(2 分钟)/ 主宰(4 分钟)全队增益
- 草丛隐身、防御塔仇恨、泉水回复、击杀播报(一血/双杀/超神)、结算 MVP

## 操作

| 动作 | 电脑 | 手机 |
|---|---|---|
| 移动 | WASD / 方向键 | 左半屏虚拟摇杆 |
| 技能 1/2/3 | 1 / 2 / 3 | 点击技能按钮 |
| 普攻(按住追击) | 空格 | 大剑按钮 |
| 闪现 / 治疗 / 回城 | F / G / B | 右侧小按钮 |
| 攻击优先级 | — | 点击 🗡️/🛡️/🏰 切换 |
| 商店 | P | 🛒 按钮 |

## 技术说明

- 单文件 `dist/index.html`(约 750KB),内联 Three.js r150,无任何外部依赖,离线可玩
- 程序化生成:地图贴图、水波、英雄/野怪低模、WebAudio 合成音效、语音播报(speechSynthesis)
- 性能:小兵 InstancedMesh、粒子池、自动降画质(低帧率时关阴影)
- 电脑 / 手机浏览器(Chrome / Edge / Safari)均可游玩

## 开发

```
index.html      开发版(引用外部文件)
style.css       HUD 样式
js/             游戏源码(a-core → g-game 按序加载)
build.js        打包脚本:node build.js → dist/index.html
```
